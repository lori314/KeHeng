# KeHeng v0.5.5 竞赛评测样例集

本目录保存三个完全合成、可公开提交的固定评测案例。每个案例均包含文本型 PDF、指标金标准、证据金标准和案例说明，用于验证当前本地规则基线，不代表生产效果或真实企业评价。

## 案例范围

| 案例 | 场景 | 关键验证 |
| --- | --- | --- |
| `case_001` | 技术优势明显 | 四项指标完整、证据跨页、确定性高分 |
| `case_002` | 材料不足 | PDF 可解析但全部指标保持未评分 |
| `case_003` | 否定与未来语义 | “正在研发、计划量产、尚未规模化”不得推断为 TRL 6/8 |

## 金标准文件

- `expected_indicators.json`：期望指标分、总分、维度分和否定语义约束。
- `expected_evidence.json`：必须命中的页码与短语、案例标识和禁止出现的其他案例标识。
- E 编号不是静态金标准，因为 E 编号由每次检索结果动态分配；评测通过页码、原文短语和引用闭环判断证据是否正确。

## 运行评测

在仓库根目录执行：

```powershell
backend\.venv\Scripts\python.exe evaluation\evaluate_pipeline.py
```

脚本使用临时知识库运行三个案例，并输出报告生成成功率、E 编号引用完整率、`task_id` 隔离正确率、关键字段完整率，以及指标匹配率和期望证据命中率。

PDF 由 `scripts/generate_evaluation_cases.py` 生成。该生成脚本只用于维护固定测试制品，不属于运行时分析链路。
